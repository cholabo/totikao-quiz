手続と制度（申請の流れと登記所のしくみ）

登記の中身ではなく、申請がどう流れ、登記所がどう動くかを問う肢をまとめた列。

  • 管轄と登記所、申請の方法（書面・電子）、登記官の調査と本人確認、取下げと却下、完了証と通知、証明書の交付、保存期間、登録免許税、審査請求、筆界特定の手続まで
  • ここは横断のルールではなく手続の一つ一つが項目になるので、この列の中身はそれぞれの縦軸（登記の種類）のページに書いてある

この列の読み方

出題の型は三つ。

  • 誰がするか（登記官か申請人か、法務局長か）、いつまでか（期間・起算点・保存期間）、どの方法か（出頭か送付か電子か、申出の様式）
  • 数字と主体を入れ替えた肢が大半で、条文の主語と期間を押さえれば解ける

下の項目は肢数の多い順。各項目の冒頭に、その手続の全体像を置いてある。

通知・失効・証明登記識別情報

  • 通知される場合
    その登記によって申請人自らが登記名義人となる場合に限られる（法21条）
    • 表示に関する登記では通知されず、分筆・分割では新たに名義人になる者がいないので通知されない（分筆後の乙土地の登記識別情報は甲土地のもの）
    • 通知を受けるのは申請人で、申請人でない抵当権者には通知されない
    • 登記名義人ごとのものなので共有ならA・Bそれぞれに通知
  • 通知されない場合
    希望しない旨の申出をあらかじめしたとき
    • 官庁・公署（希望する旨の申出があれば通知）
    • 書面申請で登記完了の時から3月、電子申請で送信できるようになった時から30日以内に受け取らないとき（規則64条）
  • 代理人
    代理人が通知を受けるには、そのための特別の委任が要る（規則62条2項）
    • 法定代理人によって申請しているときは法定代理人に通知する
  • 提供できないとき
    • 正当な理由があれば
    • 登記官は申請があった旨と
    • 真実であると思料するときは期間内にその旨の申出をすべき旨を通知する（事前通知。法23条）
  • 失効の申出
    亡失・焼失しても再通知・再発行はなく、できるのは失効の申出（規則65条）
    • 申出は「することができる」もので義務ではない
  • 証明の請求
    • 登記識別情報が有効であること
    • 通知されていないこと
    • 失効していることの証明を請求できる（規則68条）
    • 請求できるのは登記名義人とその一般承継人で、利害関係人は含まれない
    • 電子情報処理組織を使う方法でもできる
    • 住所が登記記録と違うときは変更を証する情報を提供する
    • 資格者代理人が請求するときは代理権限を証する情報を要しない
  • 合筆・合併・合体で提供を省略できる単位は「土地（建物）」で、選んだ一筆については申請人となる者全員分が要る

事前通知と本人確認情報事前通知・本人確認

  • 事前通知
    • 登記識別情報を提供できない正当な理由があるときは
    • 申請があった旨と
    • 真実であると思料するときは期間内にその旨の申出をすべき旨が登記名義人本人に通知される
    • 資格者代理人宛てにする申立ての制度はない
    • 申請前3月以内に住所の変更の登記がされたことは、本人確認調査をすべき場合として挙げられていない
  • 事前通知を省ける場合は二つ（法23条4項）: 資格者代理人の本人確認情報を登記官が相当と認めたとき、公証人の認証
    • 本人確認情報が相当と認められないときは却下ではなく、原則どおり事前通知がされる
    • 資格者代理人による申請では、まずその資格者代理人に必要な情報の提供を求める
  • 本人確認情報（規則72条）: 作成できるのはその申請を代理する資格者代理人自身
    • 面談した日時・場所・状況を明らかにする
    • 面識があるときはその旨と面識が生じた経緯、氏名を知らず又は面識がないときは提示を受けた書類の内容と申請の権限を有する登記名義人と認めた理由を明らかにする
    • 資格者代理人であることを証する情報（職印証明書など。発行後3月以内）を併せて提供する
  • 面識があるとき
    依頼を受ける以前から氏名・住所を知り、安定した継続的な関係があるとき
    • 当該申請の3月以上前に同じ申請人について本人確認情報を提供して申請したとき（3月未満は含まれない）
  • 本人確認書類
    運転免許証など有効期間のある書類は提示を受ける日において有効なもの
    • 運転免許証などが一つあればよいが、健康保険証の類だけで確認するには二以上の提示が要る
    • 面識がなくても書類の提示を受けて本人確認情報を作れる
    • 法人の場合は代表者又はこれに代わるべき者と面談する
  • 本人確認調査（法24条）は申請の権限の有無の調査で、申請意思は対象でない
    • 却下すべき場合は調査から除かれる
    • 電話等で確認できるときは本人の出頭を求めなくてよい
    • 不正登記防止申出は登記所に出頭してする
  • 事前通知への申出の期間は2週間、外国に住所があるときは4週間
    • 通知を受けるべき者が死亡したときは相続人全員から申出ができる

    • 分棟

    • 分筆・合筆の登記の抹消（表題部の登記の抹消として(十五)のかっこ書で除かれる）

管轄登記所はどこか管轄

  • 登記は不動産の所在地を管轄する登記所へ（法6条1項）
    • 建物は、登記の後に他の管轄区域にまたがっても、登記されている登記所が管轄登記所のまま
  • 新築の建物が二以上の登記所の管轄区域にまたがるときは管轄の指定を受ける
    • 指定がされるまでの間も、二以上の登記所のうち一の登記所に申請できる（甲・乙どちらでもよい）
  • 登記の後に増築・附属建物の新築・合併で他の登記所の管轄区域にまたがることになっても、管轄登記所は元の登記所のまま
    • 管轄が違う建物どうしでも合併でき、合併後の管轄は元の登記所
  • えい行移転で建物が甲登記所の管轄区域から乙登記所の管轄区域に移動したときは、乙登記所が管轄登記所として扱う
    • 所在の変更の登記は甲登記所にも乙登記所にも申請できる
  • 管轄が転属したときは登記記録が乙登記所に移送されるので申請先も乙登記所になる
    • 移送前であっても旧管轄の登記所には申請できない

取下げと却下取下げ・却下

  • 取下げは登記が完了するまでできる
    • 完了後はできない
    • 事前通知がされていても、不正な申請の疑いがあっても、完了前なら取り下げられる（不正の疑いは取下げの制限事由ではない）
    • 一の申請情報で二以上の申請をしたときは、その一部だけを取り下げられる
  • 電子申請の取下げは、電子情報処理組織を使用して取下げの情報を提供する方法による
    • 取下げのときの添付書面は、代理人によって申請されていれば代理人に交付すれば足りる
  • 却下
    補正できる不備は、登記官が定めた相当の期間内に補正すれば却下されない
    • 登記官の調査（法29条）の結果と申請が合致しないときは却下（筆界が確認できなければ地積も確かめられない）
    • 却下の決定書は電子申請でも書面で作成して交付する
    • 登記官の調査権は「当該不動産の表示に関する事項」に及び、表題部所有者の認定を除外する限定はない
  • 登記識別情報を提供できない正当な理由があるときは事前通知
    • 管轄が転属した後は、移送前でも旧登記所には申請できない
  • 一の申請情報で二以上の登記の目的を申請し、一部にだけ却下事由があるときは、その分だけが却下され、全部が却下されるのではない

筆界特定の手続筆界特定の申請

  • 管轄は対象土地の所在地で見る
    • 関係土地の所在地ではない
    • 手続記録も対象土地の所在地を管轄する登記所で保管する
  • 却下
    補正できる不備は、筆界特定登記官が定めた期間内は却下できない
    • 却下は登記官の処分とみなされ、審査請求できる
  • 申請情報の作り方
    現地の状況や主張する線は図面を利用する等の方法で明示する（図面によることが義務づけられているわけではない）
    • 他人（申請人以外の対象土地の所有権登記名義人等）が主張する線を書くのは対象土地の分で、関係土地の分ではない
    • 資料は写しを3部出し、原本は求められたときに提示する
  • 関係人は申請人以外の対象土地・関係土地の所有権登記名義人等
    • 申請人でない共有者も関係人で、意見も資料も出せる
    • 抵当権者は入らない
    • 意見・資料の提出先は筆界特定登記官で、申請人ではない
    • 出なくても筆界特定はできる
  • 通知
    • 申請があった旨の公告・関係人への通知
    • 筆界特定をした旨の申請人への通知・公告・関係人への通知は
    • いずれも筆界特定登記官がする

  • 筆界調査委員は専門的知識・経験を有する者から法務局・地方法務局の長が任命し（法127条）、事件ごとに指定する（134条）
    • 測量・実地調査は、立ち会う機会を与えれば立会いがなくてもできる

審査請求の手続審査請求

  • 審査請求は登記官を経由して、その登記官を監督する法務局・地方法務局の長にする
    • 期間の制限はない（行政不服審査法18条は適用されない）
    • 参加人の規定（行審法13条）も適用除外
  • 監督法務局長等は、理由があると認めるときは登記官に相当の処分を命じ（自らはしない。却下すべきものと認めるときも登記官に命じる）、審査請求人と登記上の利害関係人に通知する
    • 裁決をしたときは裁決書の謄本（と審理員意見書の写し）を審査請求人と登記官に交付する
  • 筆界特定は処分ではないので審査請求の対象にならない
    • 争うなら筆界確定訴訟
    • 隣地の所有者は、その登記の処分に不服がある者に当たらない
  • 裁決をしたら、審理員に提出された証拠書類は、提出者が返還しないことに同意している場合を除き速やかに返還する

地図の作り方と備付け地図

  • 地図は一筆又は二筆以上の土地ごとに作り、各土地の区画を明確にし地番を表示する（法14条2項）
    • 測量は基本三角点等（三角点、電子基準点、国土調査法の基準点など）を基礎とする
    • 恒久的な地物によるのは地積測量図の話
  • 縮尺と精度区分は土地の所在する地域の区分で決まる
    • 市街地は250分の1か500分の1で甲二まで、村落・農耕地域（田畑）は500分の1か1000分の1で乙一まで、山林・原野は1000分の1か2500分の1で乙三まで
    • 誤差の限度は地域で決まり、備付けの地図の精度ではない
  • 登記所に送付された国土調査の地籍図の写しは、その登記が完了した後に、不適当とする特別の事情がなければ地図として備え付ける（規則10条5項）
    • 国土調査法19条5項の指定を受けた測量成果の図面も同じ扱い
  • 地図に準ずる図面が表示するのは土地の位置・形状・地番で、方位は入らない
    • 公図はこの規定で法律上の根拠を得た
  • 地図に準ずる図面として備え付けた図面が修正等で地図の要件を満たすことになったときは、地図として備え付ける
