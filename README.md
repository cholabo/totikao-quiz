# 調査士 過去問（cholabo.jp）

土地家屋調査士試験の択一過去問を、年度順・復習・タイムアタックで解ける静的サイトです。
解説には条文・通達・判例の根拠カードが付き、過去問ノート（横軸「問われ方」×縦軸「登記の種類」の出題マップ）から論点ごとに読めます。

- サイト: https://cholabo.jp/
- 過去問ノート: https://cholabo.jp/note/
- 問題文は法務省公表の試験問題に基づきます。法改正で成り立たなくなった肢は現行法で成り立つ問い方に直し、問題文に「（改題）」と明記しています。
- 誤りの報告はサイト内の「誤りを報告」からお願いします。

このリポジトリは公開用の生成物です。編集はビルド側のリポジトリで行っています。
